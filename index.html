隱私權政策

讓班級資訊更容易查看，也讓資料的使用方式更清楚。

文件更新日期：2026 年 10 月 3 日 · 繁體中文

資料類型使用目的分享與第三方保存與刪除聯絡我們

1. 適用範圍

本政策說明 CheckBoard 在提供班級數位黑板服務時，如何處理與使用者相關的資料。CheckBoard 的功能包括教師建立班級、記錄每日課程與作業提醒、自訂科目、查看不同日期的黑板、顯示值日生及天氣資訊，以及讓學生與家長查看教師提供的班級內容。

本服務的營運者為 Shih Yuen Hsiao（以下稱「我們」）。本政策適用於 CheckBoard App 及其相關服務；透過連結前往的其他網站或服務，另依各自的隱私權政策處理資料。

2. 我們處理的資料

  • 帳號與登入資料：僅教師使用 Google 登入，並在 Supabase Auth 中具有登入帳號。學生與家長查看黑板不需登入，也不會因此建立 Supabase Auth 帳號。教師登入時，Supabase Auth 會處理 Google 提供的姓名、電子郵件地址、使用者識別碼，以及登入供應商、帳號建立與更新時間、確認狀態及最近登入時間等驗證紀錄。
  • 班級與黑板內容：教師輸入的班級名稱、科目、日期、課程進度、頁數、作業、提醒與值日生資訊。若內容包含姓名或其他可識別個人的資訊，該內容也屬於個人資料。
  • 天氣相關資料：CheckBoard 使用 iPhone 或 iPad 的定位服務，取得所在地區以顯示當地天氣。你可以在裝置的「設定 → 隱私權與安全性 → 定位服務 → CheckBoard」管理定位權限與精確位置設定。
  • 聯絡資料：當你向我們提出問題或資料處理請求時，我們會處理你提供的聯絡方式、訊息與處理該請求所需的資訊。

請僅輸入班級日常所需的內容，避免將身分證字號、健康資訊、私人聯絡方式或其他敏感資料寫在黑板上。

3. 資料的使用目的

上述資料依其性質，用於驗證登入、建立及管理班級、保存與顯示每日黑板內容、提供獲准查看的班級資訊、查詢天氣，以及回覆使用者提出的問題或請求。

4. 班級內容的分享與第三方服務

教師發布或分享黑板內容後，取得查看權限的人可能看見其中的班級資訊，包括內容中出現的值日生姓名。請教師在發布前確認分享對象，並確認具備提供相關個人資料的適當依據。查看者也應尊重班級成員的隱私，避免任意轉傳含個人資料的內容。

5. 資料保存與刪除

資料保存位置、保存期限與刪除方式如下：

  • 教師帳號與班級內容：教師登入帳號由 Supabase Auth 管理。學生與家長不需建立帳號即可查看黑板，但黑板內容仍可能包含可識別學生的資料。
  • 技術紀錄與備份：使用 Supabase Free 方案。
  • 帳號與個人資料刪除請求：學生與家長沒有 CheckBoard 登入帳號，因此無需辦理帳號刪除。若黑板內容包含與你或孩子相關的個人資料，可聯絡班級管理者或寄信至 fourmonth@gmail.com，提出更正或刪除請求。教師如需刪除 CheckBoard 的登入帳號或管理的班級資料，也可透過上述 Email 聯絡我們；這不會刪除教師本身的 Google 帳號。

移除 App 不一定會刪除雲端帳號或已發布的班級內容。若需要協助確認或刪除與你相關的資料，請透過本政策末尾的聯絡方式提出請求。已由其他查看者另行保存或轉傳的內容，可能無法透過 CheckBoard 刪除。

6. 你的選擇與資料請求

你可以透過下方聯絡方式，提出查詢、閱覽、取得副本、更正、停止處理或利用，以及刪除個人資料的請求。我們會依適用規定及資料的實際處理情況回覆；為避免資料被未授權的人取得，可能需要確認你的身分或班級管理權限。若請求無法全部執行，我們會說明原因。

若 App 使用裝置權限，你可在系統設定中調整已授予的權限。撤回某項權限可能影響依賴該權限的功能，且不會自動刪除先前已保存的資料。

7. 學生與未成年人的資料

班級內容可能涉及學生或未成年人。教師及管理者在輸入或分享可識別學生的資料前，應依學校規範及適用要求，確認必要性、分享範圍，以及是否需要取得家長或法定代理人的同意。

若你是家長或法定代理人，對孩子的資料有疑問，可聯絡開發者；如需我們協助處理 CheckBoard 中的資料，也可使用下方聯絡方式。

8. 資料安全

請妥善保管登入資訊及班級分享資訊。任何網路傳輸或儲存方式都無法保證完全沒有風險；若懷疑帳號或班級內容遭到未授權存取，請與我們聯絡。

9. 本政策網頁

本頁採用靜態 HTML，不包含分析腳本、廣告、表單、追蹤像素或外部字型。若本頁部署於 GitHub Pages，網站託管平台仍可能為提供服務及安全維護處理訪客 IP 位址等紀錄；相關處理方式請參閱 GitHub 一般隱私權聲明。本段僅說明政策網頁，不代表 App 的資料處理方式。

10. 政策更新

當功能或資料處理方式變更時，我們會更新本政策及頁面日期。涉及使用者權益的重要變更，將依適用要求以適當方式告知。
